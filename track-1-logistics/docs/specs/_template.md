## 1. Overview
One paragraph: what this feature is, why the business wants it, and what is out of scope.

## 2. Users
Who uses it, what they can see and do, and what they must not be able to do.

## 3. Business rules
Numbered rules (BR-01, BR-02 ...). State rules, not fields. Each rule must be testable.

## 4. API
Each endpoint: method and path, request, response, error cases and status codes.

## 5. UI
Screens, what each shows, and the loading, empty and error states.
